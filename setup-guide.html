CloudConsole Setup Guide

Panduan Instalasi Produksi pada VPS Ubuntu + aaPanel

Sistem Arsitektur

Runtime: Node.js 20 LTS
Database: PostgreSQL
Queue: Redis
Frontend: Next.js 14
⚠️ PENTING: Aplikasi ini menggunakan PostgreSQL, bukan MySQL. Pastikan Anda menginstall PostgreSQL melalui App Store aaPanel sebelum memulai.

1 Persiapan aaPanel

Install komponen berikut melalui App Store aaPanel:

  • Node.js Version Manager: Pilih versi 20.x LTS.
  • PostgreSQL: Install versi terbaru yang tersedia.
  • Redis: Install untuk menangani queue BullMQ.

Buat database PostgreSQL baru (misal: cloud_console) dan catat kredensialnya.

2 Instalasi Backend & API

Jalankan perintah berikut melalui SSH Terminal:

cd /www/wwwroot git clone cloud-console cd cloud-console npm install cp .env.example .env nano .env

Konfigurasi .env:

  • DATABASE_URL: postgresql://user:pass@localhost:5432/cloud_console?schema=public
  • AUTH_SECRET: Jalankan openssl rand -base64 32 untuk generate.
  • REDIS_HOST: 127.0.0.1
# Setup Database & Build npx prisma generate npx prisma migrate deploy npx prisma db seed npm run build

3 Manajemen Proses (PM2)

Gunakan PM2 agar aplikasi berjalan otomatis di background:

sudo npm install pm2 -g # API Server pm2 start npm --name "cloud-console-api" -- start # VPN Worker pm2 start dist/lib/queue/vpnWorker.ts --name "vpn-worker" # Cron System (Billing) pm2 start dist/lib/cron/index.ts --name "vpn-cron" pm2 save pm2 startup

4 Konfigurasi Domain & SSL

  1. Buka Website $\rightarrow$ Add Site $\rightarrow$ Masukkan Domain Anda.
  2. Klik Nama Domain $\rightarrow$ Reverse Proxy $\rightarrow$ Add Reverse Proxy.
  3. Set Target URL ke: http://127.0.0.1:3000.
  4. Buka menu SSL $\rightarrow$ Pilih Let's Encrypt $\rightarrow$ Apply.

5 Checklist Akhir

  • PostgreSQL sudah running dan migrasi selesai.
  • Redis sudah aktif.
  • PM2 status menunjukkan semua proses "online".
  • SSL aktif (HTTPS).
  • Port UDP 51820 terbuka (Jika menggunakan VPN).
